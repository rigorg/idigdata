# Public outcome catalog

Operations on :3300 owns outcome identity and approved public wording. To update the Block, run `npm run catalog:import -- <approved-export.json>` from this repository, then run tests, typecheck, and a production build. Importing is a local code change, not deployment.

The importer accepts the `outcome-catalog-2026-10-10` export contract, verifies the SHA-256 of `{ outcomes, aliases, retired_ids }`, requires 60 unique outcomes with ten in each established category, and refuses unexpected fields. Public title is the short label; public summary is the buyer result; explicitly approved public detail provides scope, what you receive, completion, and boundaries. Detail paragraphs remain readable in the outcome drawer. Empty deliverables are intentional: private scope/completion fields are never used as a fallback.

Generated `lib/catalog.ts` records the Operations public revision/hash and retired IDs. Exported aliases are authoritative for retired source IDs: only an approved equivalent successor can redirect them. Historical website aliases survive only where their target remains public or has an exported equivalent successor. Direct links use `/block/?outcome=<stable-id>`; visiting a link opens and focuses its outcome but never selects it. Saved selections resolve equivalents before restoring. A retired scope without an equivalent is retained separately, visibly flagged for review, and included in the request without selecting a replacement.

Run `npm run catalog:import-factory -- <approved-factory-export.json>` for the separate `factory-outcome-catalog-2026-10-10` projection. It requires exactly ten Factory Agentic Software outcomes and writes `lib/factory-outcome-catalog.ts`. AG can consume its `FACTORY_CATALOG_ITEMS` (name, tagline, situation) and revision metadata in the agentics experience. It is never appended to the six-face Block or its selection model. Both imports require the approved database export, not the proposed matrix fixture. Neither script deploys, changes a runtime, or touches port 3100.
